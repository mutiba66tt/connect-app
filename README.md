# ConnectApp

ConnectApp is a modern mobile-friendly web application built using Lovable and Firebase Authentication. The app provides a clean and professional user experience with authentication and communication features.

## Live Demo

🔗 App URL: https://id-preview--f48d5fe0-b48d-46ca-bea8-9b1ba19cf033.lovable.app/login

> Users can open the link and test the application directly on mobile or desktop.

## Application Pages

### Splash Screen
Displays branding and welcome screen.

### Registration Page
Allows users to create a new account using:
- Full Name
- Email
- Password

### Login Page
Allows registered users to securely log in.

### Home Page
Contains:
- Welcome Section
- Call Button
- Map Button
- Message Button
- Logout Button

---

## Installation

### Mobile Installation

1. Open the live app URL in Google Chrome.
2. Click the three-dot menu.
3. Select **Add to Home Screen**.
4. The app will be installed on the mobile home screen.
